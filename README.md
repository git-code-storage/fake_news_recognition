# Модель предсказания фейковых новостей

> Модель бинарное классификации для определения является ли статья фейковой, основываясь на её заголовке, URL и веб-домене, на котором она была размещена.

---

## Описание

Представлено два варианта решения задачи на фреймворках PyTorch и TensorFlow.
Внутри каждого фреймворка построенно 3 модели для разных архитектур: RNN, LSTM и GRU.
Векторные представления слов получены с помощью Word2Vec библиотеки Gensim

В качестве основных метрик приняты:
1. Точность (accuracy):

|  | PyTorch | TensorFlow |
| :--- | :--- |:--- |
| RNN |0.820|0.847|
| LSTM |0.991|0.855|
| GRU |0.991|0.851|
   
2. F1 мера (F1 Score):

|  | PyTorch | TensorFlow |
| :--- | :--- |:--- |
| RNN |0.875|0.905|
| LSTM |0.994|0.907|
| GRU |0.994|0.906|

3. Площадь под кривой ROC (ROC AUC Score): 

|  | PyTorch | TensorFlow |
| :--- | :--- |:--- |
| RNN |0.878|0.848|
| LSTM |0.998|0.881|
| GRU |0.999|0.871|
